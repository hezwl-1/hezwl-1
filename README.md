**Smooth Web Translator** — 网页实时自动翻译助手，由 hez 使用 GPT-5.5 开发。

- 实时自动翻译网页
- 支持 Chrome / Edge 浏览器
- 支持菜单、按钮、输入框提示补翻
- 自带翻译进度条和加载动画
- 低卡顿优化，页面切换更丝滑
- 支持一键还原原文
